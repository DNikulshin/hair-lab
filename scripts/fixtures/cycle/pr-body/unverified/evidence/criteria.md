# Критерии приёмки

Источник: секция «Готово, когда» (шаблон task).

- C1: Тело PR содержит `Closes #N` и таблицу критериев со ссылками.
- C2: Пункты `followups.md` попадают в раздел «Вне скоупа».
- C3: `pnpm test:int` выполнен на живой БД.
- C4: Раздел «Независимая оценка» содержит вердикты ревью и оценки.
