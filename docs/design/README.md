# Дизайн: направление и система

Принято в #13: направление **A «Разметка»**, радиус **12 px**, тёмная тема обязательна.
Архив отклонённых направлений — `docs/design/directions/` (можно вернуться к B или C).

## Идея

Салон как точный инструмент. Структура страницы работает как разметка чертежа: линейки
и засечки несут информацию (длительность услуги — длина штриха), а не украшают. Один громкий
жест на экран — кобальтовая линия; всё остальное держится на типографике и волосяных линейках.
Фотографии не обязательны: макет рассчитан на тонкий контент (4 услуги, 2 мастера), а когда
появятся снимки — они встают в карточки без переверстки.

## Токены

Значения живут в `apps/web/src/app/globals.css` (`:root`, `prefers-color-scheme: dark`,
`@theme inline`). Менять палитру — только там.

| Роль               | Светлая   | Тёмная    | Смысл                                   |
| ------------------ | --------- | --------- | --------------------------------------- |
| `--surface`        | `#EFEDE6` | `#131518` | фон страницы («бумага»)                 |
| `--surface-raised` | `#F8F6F0` | `#1B1E23` | карточка, поле, приподнятая поверхность |
| `--ink`            | `#17181A` | `#EFEDE6` | основной текст и линейки структуры      |
| `--muted`          | `#5C5F63` | `#A8A7A1` | второй план: подписи, описания          |
| `--accent`         | `#2438C9` | `#8FA0FF` | единственный акцент: действие, фокус    |
| `--on-accent`      | `#FFFFFF` | `#131518` | текст на акцентной заливке              |
| `--border`         | `#C5C1B5` | `#2E3238` | волосяные линейки, разделители (декор)  |

Контраст проверен (WCAG 2.x AA): текст `ink`/`surface` 15.2:1, `muted`/`surface` 5.5:1 (тёмная —
7.6:1), `accent`/`surface` 7.2:1, текст на акцентной заливке 8.5:1 (тёмная — 7.5:1).
Границы полей — не `--border`, а `--ink` (подчёркивание 1 px): так требование 3:1 выполняется
с запасом, а волосяные линейки остаются тонкими.

## Типографика

| Роль    | Семейство      | Веса          | Где                            |
| ------- | -------------- | ------------- | ------------------------------ |
| Дисплей | **Unbounded**  | 200, 300, 500 | `h1`, `h2`, цены, знак в шапке |
| Текст   | **Golos Text** | 400, 500, 600 | тело, подписи, элементы форм   |

- Оба семейства кириллические изначально; файлы вендорены в `apps/web/src/app/fonts/`
  (woff2, подмножества `latin` + `cyrillic`, лицензии OFL рядом).
- Почему не `next/font/google`: с dev-хоста `fonts.googleapis.com` отдаёт `ERR_CONNECTION_RESET`,
  и сборка без сети стала бы невоспроизводимой. Почему не `next/font/local`: нужен
  `unicode-range` на подмножество, а `local` его не проставляет — поэтому `@font-face` объявлены
  в `globals.css` рядом с токенами.
- Символ `₽` (U+20BD) в подмножествах Google отсутствует: он подставляется системным
  фолбэком. Это осознанно: цена читается как число, а символ валюты — служебный.
- Шкала: 12 / 14 / 16 / 18 / 22 / 28 / 40 / clamp(40–72) для `h1`. Трекинг дисплея отрицательный
  (`-0.02…-0.03em`), тело без трекинга, `line-height` 1.5 для текста, 1.05–1.1 для заголовков.
- Строка не длиннее ~68 символов (`max-w-2xl` для лидов).

## Сетка и ритм

- `Container`: `max-w-6xl`, боковые отступы `px-5` (мобайл) — не менять в страницах.
- Вертикальный ритм: секции `gap-10…gap-16`, карточки `gap-4`, внутри карточки `gap-3`.
- Радиус: 12 px (`--radius-card`) на карточках, полях и кнопках. Скругления не дробим:
  одно значение на всё.
- Тени не используем. Иерархия — линейкой, фоном `surface-raised` и размером кегля.
- Прайс/списки: волосяная линейка между строками, цена справа и `tabular-nums`.
- Штрих длительности (`DurationBar`) — доля от самой длинной услуги каталога; смысл в
  сравнении, а не в точном значении.

## Примитивы (`apps/web/src/shared/ui`)

| Компонент   | Назначение                                                                                                |
| ----------- | --------------------------------------------------------------------------------------------------------- |
| `Container` | горизонтальная сетка контента                                                                             |
| `Section`   | секция с заголовком `h2` и описанием, единый ритм заголовков                                              |
| `Card`      | поверхность `surface-raised` + волосяная рамка, без тени                                                  |
| `Button`    | `primary` (заливка `ink`, на hover `accent`) и `ghost` (линейка); ссылкой через `asChild`-подобный `href` |
| `Field`     | подпись + контрол; инпут/селект с подчёркиванием `ink` и фокусом `accent`                                 |

Правила: фокус виден всегда (`outline: 2px solid var(--accent)` c `outline-offset`), тап-таргет
≥ 24 px (кнопки — 44 px), `prefers-reduced-motion` уважается (анимаций почти нет: только
переход цвета 120 мс).
