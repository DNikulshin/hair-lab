# Архив направлений B и C (#13)

Владелец выбрал направление **A «Разметка»** (см. `../README.md`). B и C отклонены, но
сохранены как рабочие макеты: если понадобится сменить стилистику, начинать с них, а не с нуля.

## Как посмотреть

Каталог самодостаточный: HTML + локальные шрифты (`fonts/fonts.css`, woff2 в `fonts/files/`).

```bash
cd docs/design/directions
python3 -m http.server 8099        # затем http://127.0.0.1:8099/b-razvorot.html
```

Или открыть `b-razvorot.html` / `c-strizh.html` напрямую в браузере (`file://`) — шрифты
подхватятся, внешних запросов нет. Скриншоты рядом: `b-razvorot.png` (1440), `b-razvorot-mobile.png`
(390), то же для C.

Данные в макетах — реальные из dev-БД на момент #13 (4 услуги, 2 мастера). Контент правится
прямо в HTML: это статические страницы без сборки и без JS.

## B «Разворот» — редакционный

Кость `#E9E5DC` · чернила `#14110F` · пепел `#665F57` · бордо `#5B1F26`.
**Literata** (400/600, курсив 400) + **Golos Text** (400/500). Радиус 0.

- Заголовок в 8 колонок из 12, справа узкая колонка-подводка с линейкой слева.
- Услуги — лента в две колонки, цена справа крупной цифрой; мастера — строки с инициалами
  в круге, без карточек.
- Акцент один: бордо только на кнопке и в «Lab» знака.
- Сильная сторона: лучше всех принимает фотографии. Слабость: без фото мастера выглядят
  заглушкой.

## C «Стриж» — кинетика бренда

Ночь `#101314` · мел `#F3F4F2` · дымка `#8A9295` · мята `#6FE3C9`.
**Onest** (400/600/800) + **Golos Text** (400/500). Радиус 0.

- Одна летящая кривая (inline SVG) проходит сквозь заголовок; заголовок строчный, вес 800.
- Тёмная сцена как основная; мята только на действиях (активный пункт, кнопка, «глаз» кривой).
- На мобайле активный пункт меню показан цветом, не плиткой: подложка ломала перенос строки.
- Сильная сторона: узнаваемость с первого экрана, идеально для PWA в тёмной теме.
  Слабость: тёмный сайт для салона — заявление; мяту легко перелить.

## Если возвращаться

1. Взять палитру и шрифты из соответствующего раздела выше.
2. Токены в `apps/web/src/app/globals.css` — те же роли (`surface/raised/ink/muted/accent/border`),
   меняются только значения; компоненты переписывать не нужно.
3. Проверить контраст и тап-таргеты по чек-листу в `../README.md` и `docs/qa-web.md`.
4. Шрифты: у B — Literata 400/600 + 400 italic; у C — Onest 400/600/800. Подмножества
   `latin` + `cyrillic` достаточно; файлы лежат в `fonts/files/`.
