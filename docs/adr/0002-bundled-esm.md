# 0002. Сборка пакетов через tsup (ESM)

- **Статус:** принято
- **Дата:** 2025-11-13

## Контекст

Монорепо на Node 22. Нужны предсказуемые ESM-пакеты без ручных `.js`-расширений
в импортах и без `ts-node` в проде. Next.js и Fastify оба умеют работать с ESM.

## Решение

- Все пакеты — `"type": "module"`, относительные импорты без расширения,
  `moduleResolution: "bundler"`.
- `packages/contracts` и `apps/api` собираются `tsup` (esbuild + dts для контрактов).
  Зависимости не бандлятся — остаются внешними.
- `apps/web` собирает Next.js; `tsconfig` наследует `tooling/tsconfig/next.json`.
- В `tooling/tsconfig/base.json` стоит `ignoreDeprecations: "6.0"`: tsup-dts подставляет
  `baseUrl`, который TypeScript 6 считает устаревшим. Убрать, когда tsup перестанет его добавлять.

## Последствия

- Положительные: одинаковый стиль импортов во всех пакетах, быстрая сборка, d.ts из коробки.
- Отрицательные: собранный ESM-бандл не даёт «нативного» запуска исходников без сборки
  (dev-режим API идёт через `tsx`).
- Запрещено: писать в импортах `.js`-расширения и заводить второй сборщик без ADR.
