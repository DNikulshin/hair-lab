# 0004. ЮKassa, SMTP-почта, nginx на хосте

- **Статус:** принято
- **Дата:** 2025-11-13

## Контекст

Запись оплачивается полностью онлайн. Уведомления клиенту и салону нужны сразу после записи
и оплаты. Прод — один VPS, TLS и маршрутизация требуют reverse proxy.

## Решение

- **Платежи:** ЮKassa, на этапе разработки — тестовый магазин, режим задаётся `PAYMENTS_MODE`.
  Сумма и назначение считаются на сервере; вебхук идемпотентен; запись подтверждается оплатой.
- **Почта:** Google Workspace, SMTP `smtp.gmail.com:465`, пароль приложения; нужны SPF/DKIM/DMARC.
  Отправка через outbox и воркер, вне транзакции записи. Яндекс 360 остаётся заменой
  на уровне конфигурации.
- **Reverse proxy:** nginx на хосте; контейнеры публикуются только на `127.0.0.1`,
  API доступен как `/api/*`.

## Последствия

- Положительные: нет лишних контейнеров, TLS и кэш статики — на зрелом инструменте,
  провайдеры платежей и почты заменяемы на уровне адаптеров.
- Отрицательные: конфиг nginx живёт на хосте и обновляется вручную — вынести в git
  (`deploy/nginx/`) и описать в docs; смена провайдера почты требует правки конфигурации.
- Запрещено: публиковать порты контейнеров наружу, принимать сумму платежа с клиента,
  логировать тела вебхуков и письма с персональными данными.
