# 0001. API на Fastify 5

- **Статус:** принято
- **Дата:** 2025-11-13

## Контекст

API обслуживает сайт, PWA и в перспективе мобильное приложение (Expo). Нужны схема-первый
контракт, минимальные накладные расходы на один экземпляр и предсказуемая экосистема плагинов.

## Решение

- HTTP-слой — Fastify 5, features оформляются инкапсулированными плагинами.
- Источник валидации и сериализации — Zod-схемы из `packages/contracts`
  через `fastify-type-provider-zod`. Схемы не дублируются в API.
- Единый формат ошибок `{ error: { code, message, requestId } }`, коды — из контрактов.
- Логи — pino (встроен), в development — `pino-pretty`.

## Последствия

- Положительные: одна схема на сервере и клиенте, быстрая сериализация, простая композиция фич.
- Отрицательные: тип-провайдер Zod связывает версии Fastify/Zod — обновлять вместе.
- Запрещено: описывать схемы запросов/ответов вручную мимо `contracts`.
