# @hair-lab/contracts

Zod-схемы и типы публичного API. Источник истины для web, api и будущего мобильного клиента.

## Правила

- Типы не пишутся руками: только `z.infer` от схемы.
- Разрешены только `zod` и относительные импорты. Запрещены `node:*`, DOM, React, Fastify, Prisma —
  это проверяет `pnpm check:arch`.
- Изменения только обратно совместимые: новые поля опциональны, удаление — через депрекацию.
  Старые клиенты (кэш PWA, будущее приложение) живут неделями.
- Деньги — в копейках (`moneySchema.amountMinor`), время — ISO 8601 с зоной (в БД UTC).

## Структура

```
src/
  common/   # переиспользуемые примитивы: id, деньги, время, пагинация, ошибки
  health/   # GET /health
  index.ts  # единственная публичная точка входа
```

Новый домен добавляется папкой `src/<домен>/<домен>.contract.ts` и строкой `export *` в `index.ts`.

## Сборка

```bash
pnpm --filter @hair-lab/contracts build   # обязательно перед typecheck и тестами приложений
```
